Keyboard helper macOS

  1. In Finder, double-click native/install.command.
  2. Click Request macOS keyboard permission. Enable MeowCheats Keyboard in System Settings → Privacy & Security → Accessibility (and your browser if asked).
  3. Click Check keyboard helper.

Installed but not connected? Remove MeowCheats Keyboard from Accessibility, rerun native/install.command, then request keyboard permission again.
